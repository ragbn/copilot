# Zava Copilot in PowerPoint — Audience Prompt Guide

Use this guide during the **Copilot in PowerPoint** section of the workshop.

## Before you start

For this section, the facilitator may provide:

- a **starter PowerPoint deck**
- a **Zava source PDF / performance brief**
- optionally, a **Zava Brand Kit or branded template**

If a starter deck is provided:

1. Download it.
2. Save your own copy to OneDrive.
3. Rename it if useful, for example:

   `YourName_Zava_PowerPoint_Lab.pptx`

4. Open it in PowerPoint with Copilot available.
5. Follow the same prompts as the facilitator.

> **Important**
> - We are focusing on standard Copilot in PowerPoint experiences.
> - Some capabilities may vary by tenant configuration.
> - Review generated content, numbers, and speaker notes before using them.
> - If a feature is unavailable, continue with the next task rather than spending the exercise troubleshooting it.

---

# Scenario

You are **Corey Gray**, Customer Experience Program Manager at **Zava**.

Zava is preparing a leadership briefing on the **Team Challenge pilot**.

Corey has:
- a source report
- a draft presentation
- performance data
- a Zava brand style
- limited time to turn the material into a concise, presenter-ready leadership deck

The PowerPoint workflow is:

**Source → Script → Build → Refine → Visualise → Brand → Present**

---

# 1. Create the presentation script from a source document

Attach or reference the source PDF supplied by the facilitator.

## Prompt

```text
Using only the attached source document, prepare a script for a Zava leadership briefing.

Focus on the evidence that is most relevant to the Team Challenge pilot and leadership decision-making.

Structure it slide-by-slide.

For each slide provide:
- slide title
- 2–4 concise leadership-ready points
- the specific evidence or statistic supporting the point
- the relevant source page or section

Separate facts from the source from any implications you infer for Zava.

Do not add unsupported claims.

Keep the presentation to 6 slides.

Do not design the slides yet.
```

## What to look for

- Does Copilot distinguish source facts from interpretation?
- Does it avoid adding unsupported numbers?
- Is the storyline concise enough for leadership?

---

# 2. Challenge the storyline before building slides

## Prompt

```text
Review this proposed storyline as a skeptical Zava executive.

Identify:
- any statement that overreaches the source evidence
- any important evidence we have omitted
- any slide that feels repetitive
- any point that is too detailed for leadership

Then give me a revised 6-slide structure.
```

## Why this matters

A good presentation starts with the story, not the design.

---

# 3. Build the slide deck

Once the storyline is approved:

```text
Use the revised script to create the presentation.

Keep the content concise.

Preserve the distinction between source evidence and Zava implications.

Where numerical evidence would be clearer visually, use a simple chart or visual rather than putting all the numbers into bullets.

Do not add unsupported statistics.
```

---

# 4. Make slide titles conclusion-led

Select a slide with a generic title.

## Prompt

```text
Rewrite this slide title so it communicates the conclusion rather than only naming the topic.

Give me 3 alternatives.

Keep each title concise and leadership-friendly.
```

Example:

Instead of:

`Pilot Adoption and Retention`

Aim for something like:

`Pilot exceeds adoption targets, but retention remains the key scale risk`

---

# 5. Condense a text-heavy slide

Select a dense slide.

## Prompt

```text
Condense this slide to no more than 3 points.

Preserve all important numbers and the main conclusion.

Remove repetition and implementation detail.
```

### Optional refinement

```text
Rewrite this slide for senior leadership.

Emphasize:
- business impact
- decision required
- evidence

Remove operational detail that does not change the decision.
```

---

# 6. Add a missing decision slide

## Prompt

```text
Add a slide after this one called:

What leadership needs to decide

Use the current presentation to identify the 3 most important decisions or approvals required.

Keep each decision to one short sentence.
```

---

# 7. Add a slide from a source file

Attach or reference the Zava performance brief.

## Prompt

```text
Using only the attached Zava Team Challenge performance brief, add one slide explaining the biggest remaining pilot risk.

Use:
- one conclusion-led title
- no more than 3 supporting points
- the specific evidence or metric behind each point

Do not use information from other sources.
```

---

# 8. Turn a bullet list into a visual

Select a slide that contains a sequence or process.

## Prompt

```text
Replace the current bullet list with a simple visual showing:

Eligible Employees → Opt-in → Week-3 Active → Week-6 Complete

Keep the underlying numbers unchanged.

Make the visual easy to understand at a glance.
```

### Alternative

```text
Transform this content into a simple 4-step SmartArt-style process.

Keep the same meaning and reduce the amount of visible text.
```

---

# 9. Add or replace an image

## Prompt

```text
Add a relevant image representing employees participating in a workplace wellness challenge.

Keep the image professional, inclusive, and appropriate for an enterprise leadership presentation.

Do not cover or reduce the readability of the slide content.
```

### Replace an unsuitable image

```text
Replace the current image with one that better communicates collaborative workplace wellness.

Keep the layout and text unchanged.
```

---

# 10. Apply the Zava brand

If the Zava Brand Kit is available, select it before running the prompt.

## Prompt

```text
Reformat this presentation to follow the Zava brand style.

Keep the content and underlying facts unchanged.

Make typography, colors, imagery, and layouts consistent across the deck.
```

### Brand check

```text
Review this presentation against the Zava brand style.

Identify slides with:
- inconsistent typography
- inconsistent colors
- weak visual hierarchy
- layout inconsistencies
- imagery that does not fit the brand

Do not change anything yet.
```

---

# 11. Improve visual hierarchy

## Prompt

```text
Improve the visual hierarchy of this presentation.

Keep each slide focused on one message.

Prefer:
- charts
- large numbers
- simple comparisons
- short text blocks

over dense bullet lists.

Do not change any underlying statistics or conclusions.
```

---

# 12. Summarize and review the deck

## Prompt

```text
Summarize this presentation in 5 bullets.

Tell me:
- the main recommendation
- the strongest evidence
- the biggest remaining risk
- the leadership decision required
- which slide provides the strongest support
```

---

# 13. Find weaknesses before presenting

## Prompt

```text
Review this presentation before I present it to leadership.

Identify:
- repetition
- unsupported claims
- inconsistent terminology
- overly dense slides
- weak slide titles
- slides where the conclusion is unclear

Tell me what you would change before editing anything.
```

---

# 14. Generate speaker notes

## Prompt

```text
Review the full presentation and add speaker notes for each slide.

For every slide include:
- Purpose: what this slide is trying to communicate
- What to say: speaker-ready explanation
- Evidence: numbers or facts worth saying aloud
- Delivery cue: where to pause or emphasize
- Transition: one sentence into the next slide
- Suggested speaking time

Keep the full presentation within 12 minutes.

Do not change the slide content.
```

---

# 15. Make speaker notes more natural

## Prompt

```text
Rewrite the speaker notes to sound more conversational.

Use shorter sentences.

Do not make them sound scripted or overly formal.

Keep the facts and timing unchanged.
```

---

# 16. Prepare for difficult leadership questions

## Prompt

```text
Using only the presentation and its source material, add a section to the final slide's speaker notes called:

Likely leadership questions

Give me the 8 hardest questions leadership could reasonably ask.

Focus on:
- interpretation of the data
- pilot scalability
- customer differences
- product reliability
- whether the evidence is sufficient

For each question:
- provide a concise evidence-based answer
- clearly say when the available evidence is not sufficient to answer confidently
```

---

# 17. Create a concise executive summary slide

## Prompt

```text
Create a new executive-summary slide at the beginning of the presentation.

Use:
- one recommendation
- 3 supporting facts
- the biggest remaining risk
- the leadership decision required

Keep it readable in under 30 seconds.
```

---

# 18. Reorder the story

## Prompt

```text
Review the current slide order.

Recommend a better sequence for a leadership audience.

Prioritize:
1. conclusion
2. evidence
3. risk
4. decision

Explain the proposed order before making changes.
```

# Useful PowerPoint Copilot follow-up prompts

## Shorten a title

```text
Make this title shorter and more conclusion-led.
```

## Reduce clutter

```text
Reduce visible text by 40% without losing the main message.
```

## Preserve facts

```text
Improve the wording and layout, but do not change any numbers or claims.
```

## Ask for evidence

```text
For each claim on this slide, tell me which source supports it.
```

## Improve one slide only

```text
Improve only this slide.

Do not change any other slide in the presentation.
```

## Make a slide leadership-ready

```text
Rewrite this slide for a senior leadership audience.

Lead with the implication, not the background.
```

# A simple mental model

| Task | Pattern |
|---|---|
| Understand a long source | **Script** |
| Check the storyline | **Challenge** |
| Turn the script into a deck | **Build** |
| Improve the message | **Rewrite / condense** |
| Add missing content | **Add slide** |
| Make information easier to scan | **Visualise** |
| Keep the deck consistent | **Brand** |
| Prepare to deliver | **Speaker notes** |
| Prepare for Q&A | **Leadership questions** |

---

# Final reminder

A strong Copilot in PowerPoint workflow is not:

**"Create me a presentation."**

It is:

**Source → Storyline → Build → Critique → Refine → Visualise → Brand → Rehearse**
